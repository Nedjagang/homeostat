Tier 0 · free

Answered with nothing retrieved?

Fabricated by definition. Score 0, done.

Tier 1 · free

Word overlap with the docs

Grounded answers quote the policy. High overlap → cleared, no judge call.

Tier 2 · paid

LLM judge

Score 0–1 + one-line reason. Only suspicious answers + a 2% honesty sample.

~73% fewer judge calls — and the alert still fires.

What genuinely broke — four postmortems in the repo
Bug 1

The model refused to lie

Strong models resist bad prompts. Real regressions ship as releases: prompt + cheaper model, together.

Bug 2

−7,885-second timeout

Laptop suspend → dead sockets → LLM client with no default timeout froze the loop while “alive” stayed green.

Bug 3

MODEL=5440

Dell ships a factory env var Model. Windows env is case-insensitive. Our bot tried to call a deployment named “5440”.
